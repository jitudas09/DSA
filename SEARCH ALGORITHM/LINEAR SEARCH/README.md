# 🔎 Linear Search

A simple project based on the **Linear Search Algorithm**.

## 📌 About

Linear Search is a simple searching algorithm used to find a specific element in an array or list.

It checks each element **one by one from the beginning** until the target element is found or the entire array has been checked.

## ⚙️ How It Works

1. Start from the first element of the array.
2. Compare the current element with the target value.
3. If they are equal, the element is found.
4. If they are not equal, move to the next element.
5. Continue until the target is found or the array ends.
6. If the target is not found, return an appropriate result.

## ⏱️ Time Complexity

| Case         | Complexity |
| ------------ | ---------- |
| Best Case    | O(1)       |
| Average Case | O(n)       |
| Worst Case   | O(n)       |

**Space Complexity:** O(1)

## ✅ Advantages

* Simple and easy to understand
* Works with both sorted and unsorted data
* Easy to implement
* Suitable for small datasets

## ⚠️ Limitations

* Slow for large datasets
* May need to check every element
* Less efficient than Binary Search for large sorted arrays

## 🔄 Linear Search vs Binary Search

| Feature          | Linear Search          | Binary Search      |
| ---------------- | ---------------------- | ------------------ |
| Sorting Required | No                     | Yes                |
| Best Case        | O(1)                   | O(1)               |
| Worst Case       | O(n)                   | O(log n)           |
| Approach         | Sequential             | Divide and Conquer |
| Suitable For     | Small or unsorted data | Large sorted data  |

## 🎯 Key Concept

> **Linear Search checks elements sequentially until the target is found or the entire array is searched.**
