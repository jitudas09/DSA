# 🟣 Merge Sort

An implementation of the **Merge Sort Algorithm**.

## 📌 About

Merge Sort is an efficient **Divide and Conquer** sorting algorithm.

It divides the array into smaller parts, sorts those parts, and then merges them to produce the final sorted array.

## ⚙️ How It Works

1. Divide the array into two halves.
2. Continue dividing until each part contains one element.
3. Sort the smaller parts.
4. Merge the sorted parts together.
5. Continue until the complete array is sorted.

## ⏱️ Time Complexity

| Case         | Complexity |
| ------------ | ---------- |
| Best Case    | O(n log n) |
| Average Case | O(n log n) |
| Worst Case   | O(n log n) |

**Space Complexity:** O(n)

## ✅ Features

* Efficient for large datasets
* Uses Divide and Conquer
* Consistent O(n log n) time complexity
* Stable sorting algorithm
