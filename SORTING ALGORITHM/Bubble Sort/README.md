# 🔵 Bubble Sort

A simple implementation of the **Bubble Sort Algorithm**.

## 📌 About

Bubble Sort is a simple **comparison-based sorting algorithm**.

It repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each pass, the largest unsorted element moves to its correct position.

## ⚙️ How It Works

1. Compare two adjacent elements.
2. Swap them if they are in the wrong order.
3. Continue until the end of the array.
4. Repeat the process until the array becomes sorted.

## ⏱️ Time Complexity

| Case         | Complexity |
| ------------ | ---------- |
| Best Case    | O(n)       |
| Average Case | O(n²)      |
| Worst Case   | O(n²)      |

**Space Complexity:** O(1)

## ✅ Features

* Simple and easy to understand
* Easy to implement
* In-place sorting algorithm
* Suitable for small datasets

## ⚠️ Limitation

Bubble Sort is inefficient for large datasets because its average and worst-case time complexity is **O(n²)**.
