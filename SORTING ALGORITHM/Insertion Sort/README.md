# 🟢 Insertion Sort

A simple implementation of the **Insertion Sort Algorithm**.

## 📌 About

Insertion Sort is a **comparison-based sorting algorithm** that builds the sorted portion of an array one element at a time.

Each element is placed into its correct position among the previously sorted elements.

## ⚙️ How It Works

1. Start from the second element.
2. Compare it with the elements before it.
3. Shift larger elements to the right.
4. Insert the current element into its correct position.
5. Repeat until the entire array is sorted.

## ⏱️ Time Complexity

| Case         | Complexity |
| ------------ | ---------- |
| Best Case    | O(n)       |
| Average Case | O(n²)      |
| Worst Case   | O(n²)      |

**Space Complexity:** O(1)

## ✅ Features

* Simple and easy to understand
* In-place sorting algorithm
* Efficient for small datasets
* Performs well when the data is nearly sorted
