# C++ Class

This repository contains a basic implementation of **Classes** in C++. It is created to learn the fundamentals of **Object-Oriented Programming (OOP)**.

## 📚 Topics Covered

- Class
- Object
- Data Members
- Member Functions
- Access Specifiers
  - `private`
  - `public`
- Setter Function
- Getter Function
- Encapsulation (Basic)

## 📂 Project Structure

```
.
├── class.cpp
└── README.md
```

## 🚀 Features

- Create a `Teacher` class
- Store teacher information using data members
- Demonstrate the use of `private` and `public` access specifiers
- Access private data through setter and getter functions
- Understand the basics of encapsulation

## 🎯 Learning Objectives

After completing this project, you will understand:

- What is a Class?
- What is an Object?
- How to create and use member functions
- The difference between `private` and `public`
- Why setter and getter functions are used
- The basics of encapsulation in C++
